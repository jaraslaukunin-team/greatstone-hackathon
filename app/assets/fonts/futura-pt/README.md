# Futura PT

Шрифт бренда PicPac (брендбук, раздел «Типографика → сайт»). Лицензионный (ParaType),
в репозиторий не входит. Положите сюда файлы с точными именами:

- FuturaPT-Light.otf
- FuturaPT-Book.otf
- FuturaPT-Medium.otf
- FuturaPT-Demi.otf
- FuturaPT-Bold.otf

`.ttf` тоже подходит. Подключение — `src/theme/fonts.ts`, перезапуск Metro после добавления файлов.
Пока файлов нет, приложение работает на системном шрифте.
