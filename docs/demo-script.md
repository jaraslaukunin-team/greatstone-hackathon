# Сценарий демо PicPac

## Подготовка

1. Поднять API (мок локально или настоящий на VPS):
   - мок: `npm run mock-api`
   - настоящий: выставить `EXPO_PUBLIC_API_URL` на адрес тиммейта
2. Запустить приложение: `npm start -w app`
3. Запасной вариант без APK: Expo Go + тот же `EXPO_PUBLIC_API_URL`
4. APK: `npx eas-cli@latest build -p android --profile preview` из папки `app`

Тестовый код входа: `000000`.  
Оператор: контакт с подстрокой `operator` (например `operator@test.local`).

## Обязательный путь (книги)

1. Открыть приложение → «Продолжить как гость» или вход по коду.
2. Главная → «Собрать фотокнигу» → выбрать линейку и вариант.
3. Создать проект → загрузить 8–12 фото.
4. Дождаться автомакета → обзор книги → открыть разворот, поменять фото местами.
5. «К проверке» → исправить/пропустить предупреждения → в корзину.
6. Оформление: доставка → оплата (тестовый режим) → подтверждение.
7. Заказы → открыть заказ → лента статусов.
8. (Опционально) написать в поддержку по заказу.

## Дополнительно

- **Печать фото:** Главная → «Напечатать фото» → формат → лента кадров → кадрирование → проверка → заказ.
- **Выпускной альбом:** создать альбом → пригласить по `picpac://invite/...` → прогресс участников.
- **AI:** согласие → промпт → До/После → в книгу или на печать.
- **Оператор:** войти как `operator@test.local` / `000000` → Профиль → очередь → сменить статус.
- **Сбой сети:** Профиль → «Имитация сбоя сети» → убедиться, что запросы падают с сетевой ошибкой; выключить переключатель.

## Интеграция с VPS

Когда API на VPS готов:

```bash
# Windows PowerShell
$env:EXPO_PUBLIC_API_URL="https://YOUR_API_HOST"
npm start -w app
```

Пройти обязательный путь ещё раз. Расхождения контракта править в `@picpac/shared` вместе с тиммейтом.
